### B1 backup (plan 18), built 22-10-2026

B1 is built: the mandi-backup crate and ten backup_* commands, working in /Users/faisalhanif/MyProfile/My Projects /Fruit Mandi Parallel/d5. The crate takes a consistent snapshot while the app runs, checks it, and keeps local copies (last 48). USB and cloud copies are encrypted (zstd then age, 24-symbol key shown once, kept in the Credential Manager only). USB keeps the last 30; the cloud keeps 30 daily, 12 monthly and one per year. A cloud copy goes into an outbox first and leaves it only after the upload is downloaded again and checksummed, so no internet means a queue retried every 10 minutes, not a lost copy. A scheduler decides what is due: a copy every 15 minutes while data changes, a daily USB and cloud copy at closing time, queue retry, and a copy when a USB drive is plugged in. Restore, preview and test restore are in place; restore makes and checks a safety copy first, and a wrong key or a damaged file changes nothing. E2E-18 passes from the local folder, the USB folder and the cloud stand-in, and on a fresh computer with only the typed key. Balances, journal hashes and audit hashes come back identical. The cloud is a trait with a local-folder stand-in and an object_store (S3/R2) adapter; the S3 path is untested against a real endpoint (D5-Q2). pnpm gen:types added 31 new binding files and changed no existing one.
