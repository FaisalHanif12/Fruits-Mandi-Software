How to read this book

Every page is one thing you can do in the app. The page shows a drawing of the screen. The drawing is simple, but the buttons and fields are in the same places as in your app.

Red number
on the drawing = the step with the same number. Do the steps in order.
Yellow box
the exact words and numbers to type.
Green box
what you must see. If you see something else, the app is wrong.
Orange box
a wrong entry. The app must refuse it with a clear message. Do not save it.
Purple box
"Not the same as": a look-alike screen. Do not mix them up.
Blue bar
"Open it": which menu to click to reach the screen.

Words in the drawings

Urdu words are written as the app shows them. The small English word under or beside it tells you what it means. In the steps, an Urdu word is followed by its English in brackets, for example محفوظ کریں (Save).

The order of the book

Index → Sales → Cash book → Gardens → Trips → Partners → Analytics → Reports → Backup → Settings → Dashboard. The same order as the menu of the app.

The tests use the worked day of the PRD: Cash 50,000. Rahim has an open advance of 15,000. Partners A 40%, B 30%, C 30%. Sellers Rahim and Karim. Buyers Akram and Arshad. This is called the fresh start.

WayWhen to use it

Fresh start, 5 steps (open the Terminal app)

# 1. Close the app window. In the Terminal that runs the app press Ctrl+C.
cd "/Users/faisalhanif/MyProfile/My Projects /Fruit Mandi Parallel/d5"
APP="$HOME/Library/Application Support/pk.mandisoftware.app"

# 2. Keep the old data under another name (nothing is lost).
mv "$APP" "$APP.old-$(date +%Y%m%d-%H%M)"

# 3. Make the opening position. First time takes a few minutes.
#    If a Keychain window asks, type your Mac password and choose Always Allow.

# 4. Put it where the app reads it.

These commands were not run on your Mac by the lead. If the app says the data is damaged, put the .old folder back and tell tech-lead. Some tests (marked Fresh start) need this again from the beginning.

Which date to type

Leave the date box as it is. It already shows today. The PRD calls the days 10-10 and 11-10, but the numbers do not depend on the date. Using today makes the dashboard (it shows "today") agree with the PRD. Where a test needs an old date, the page tells you which date to type. A date on or before the closed-up-to date, or after today, is refused.
